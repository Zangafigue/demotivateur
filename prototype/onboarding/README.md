# Prototype onboarding

Prototype sans dépendance du premier parcours Démotivateur.

## Lancer

Ouvrir `index.html` dans un navigateur moderne. Aucun serveur, compte ou accès réseau n'est nécessaire.

Le prototype :

- présente huit étapes progressives ;
- contrôle les réponses nécessaires ;
- limite les déclencheurs initiaux à deux ;
- génère un résumé et un exemple de première intervention ;
- conserve le brouillon dans le stockage local du navigateur ;
- permet d'effacer toutes les réponses.

Il ne programme aucune notification et n'envoie aucune donnée.

## But du test

Observer :

- si la promesse et les limites sont comprises ;
- où l'utilisateur hésite ou abandonne ;
- quelles questions semblent intrusives ou inutiles ;
- si le résumé correspond à ce qu'il pense avoir accepté ;
- si le premier message paraît utile, irritant ou trop loin.
